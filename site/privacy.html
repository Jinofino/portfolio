Hosting su GitHub Pages

Questo sito web è ospitato su GitHub Pages, un servizio fornito da GitHub, Inc. negli Stati Uniti. Quando apri una pagina, il tuo browser invia ai server di GitHub il tuo indirizzo IP e informazioni tecniche (come il browser utilizzato e l'orario di accesso). GitHub ne ha bisogno per erogare la pagina e registra e conserva l'indirizzo IP per finalità di sicurezza tecnica. Non ho accesso a questi log e non li utilizzo in alcun modo.

La base giuridica è il mio legittimo interesse a presentare questo sito web in modo sicuro e affidabile (Articolo 6(1)(f) GDPR). GitHub trasferisce i dati negli Stati Uniti in base alla propria certificazione secondo l'EU-U.S. Data Privacy Framework. Per ulteriori informazioni, consulta la GitHub General Privacy Statement.
